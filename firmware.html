Each file has two addresses. sluissantos.github.io is the stable one, live about a minute after an upload; raw.githubusercontent.com answers at once but may serve an older copy for up to 5 min after a replacement. Both are HTTPS only: a plain http:// request gets a redirect to HTTPS.

Upload

The file is committed to the fw/ folder of this public repository, so anyone with the address can download it. A file with the same name is replaced.

From an HTTP client

curl -L -o firmware.bin https://sluissantos.github.io/fw/<name>
